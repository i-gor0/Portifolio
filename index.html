About Me

Olá! Me chamo Igor Antunes, sou estudante de Análise e Desenvolvimento de Sistemas e desenvolvedor Full Stack em constante evolução. Tenho interesse genuíno por soluções tecnológicas que unam funcionalidade, performance e uma boa experiência para o usuário final. Atuo no desenvolvimento de aplicações web completas, desde o back-end — com Java, Spring Boot e bancos de dados relacionais (MySQL) — até o front-end, utilizando HTML, CSS, JavaScript e bibliotecas modernas. Também possuo familiaridade com APIs RESTful, integração com dispositivos físicos via Arduino, e boas práticas de versionamento com Git. Meu perfil combina raciocínio lógico com criatividade e visão sistêmica. Busco sempre escrever um código limpo, escalável e alinhado às regras de negócio. Acredito que tecnologia deve servir às pessoas, e não o contrário — por isso, valorizo tanto a clareza nos processos quanto a eficiência nas soluções. Sou movido por aprendizado constante e desafios que exijam pensamento crítico, autonomia e inovação. Estou pronto para contribuir em equipes que valorizam qualidade, colaboração e impacto real.

  • Projeto Full Stack: Monitoramento de Lixeiras Inteligentes

    Este foi o maior e mais desafiador projeto que desenvolvi até o momento — meu Trabalho de Conclusão de Curso, desenvolvido em equipe, com o objetivo de criar uma solução web para monitoramento remoto de lixeiras inteligentes integradas a sensores IoT. Minha principal atuação foi no back-end, onde fui responsável por estruturar a API RESTful em Java utilizando Spring Boot, conectando o sistema a um banco de dados relacional (MySQL) e definindo as regras de negócio. Também trabalhei com integração de dados recebidos via requisições HTTP simulando o Arduino, representando status como nível de enchimento da lixeira e localização GPS. Além do back-end, auxiliei no front-end garantindo que as requisições fossem tratadas corretamente — especialmente nas partes de exibição em tempo real, autenticação de usuários e painel administrativo. Isso exigiu uma colaboração direta com o time de front e domínio dos fluxos de dados entre as camadas da aplicação.

    Tecnologias utilizadas:
    Java + Spring Boot + MySQL
    HTML, CSS, JavaScript
    API REST Integração com dispositivos simulando sensores via HTTP Destaques técnicos:
    Sistema de autenticação e autorização com perfis distintos Estrutura robusta de endpoints RESTful Dashboard web com status dinâmico das lixeiras Suporte a dados de localização para futura integração com mapas
    Impacto:
    Esse projeto representou um marco importante na minha formação. Além de aplicar conceitos de desenvolvimento full stack em um contexto real, aprendi a lidar com desafios como integração com hardware, modelagem de dados, segurança da informação e comunicação entre camadas.
